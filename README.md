# PyGame Top-Down Shooter

A simple top-down shooter game built with PyGame. This was my first Python project, created while learning programming and game development concepts.

## About The Project

This is a basic top-down shooter where the player controls a character and shoot green blobs. I built this to learn Python basics and get hands-on experience with:
- Object-oriented programming
- Game loops and event handling
- Basic collision detection
- File management
- User input processing

## Technologies Used

- Python
- PyGame library

## What I Learned

This project helped me understand:
- The basics of Python syntax and structure
- Object-oriented programming concepts (classes, inheritance)
- Game development fundamentals
- Event-driven programming
- Basic graphics and animation

This was my first programming project, created while learning Python. While basic, it helped me understand fundamental programming concepts that I've built upon in later projects.
